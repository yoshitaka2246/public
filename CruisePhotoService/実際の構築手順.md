# 実際のAWSにおける構築手順
実際にAWS内でのシステム構築手順を説明します。

ソースコードの説明は省きます

## 1. S3バケットの作成
以下の３つのバケットを作成します。
- 写真アップロード先（プライベート）
  - パブリックアクセスをすべてブロック
「アクセス許可」のCORS設定で以下のJSONを追加する。
```json
[
    {
        "AllowedHeaders": [
            "*"
        ],
        "AllowedMethods": [
            "PUT",
            "POST",
            "HEAD"
        ],
        "AllowedOrigins": [
            "http://[管理者ページのURL].s3-website.ap-northeast-3.amazonaws.com"
        ],
        "ExposeHeaders": [
            "ETag"
        ]
    }
]
```




- カタログ公開用（パブリック）
  - パブリックアクセスをブロックをオフ
  - プロパティから静的Webサイトホスティングを「有効にする」
  - インデックスドキュメントは`latest.html`
  - 「アクセス許可」タブで「バケットポリシー」を編集
```json
{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Sid": "PublicReadGetObject",
            "Effect": "Allow",
            "Principal": "*",
            "Action": "s3:GetObject",
            "Resource": "arn:aws:s3:::[YOUR-BUCKET-NAME]/*" //このカタログ公開用のバケットの名前に変更する
        }
    ]
}
```
このバケットのルートにカタログページに適用する`style.css`と`main.js`をアップロードする。


- 管理者アップロードページ用（パブリック）
パブリックアクセスを許可し、静的Webサイトホスティングを有効にします。

インデックスドキュメントは`UploadPage.html`とします。

カタログ公開バケットと同様に以下のバケットポリシーを設定し、`s3:GetObject`を許可します。
```json
{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Sid": "PublicReadGetObject",
            "Effect": "Allow",
            "Principal": "*",
            "Action": "s3:GetObject",
            "Resource": "arn:aws:s3:::[CATALOG_BUCKET_NAME]/*" //このカタログ公開用のバケットの名前に変更する
        }
    ]
}
```
このバケットに`UploadPage.html`とそれに適用する`style.css`と`upload.js`をアップロードします。


## IAMロールの準備
Lambda関数がS3にアクセスするための権限（ロール）を作成します。

- GetSignedURL用のロール
IAMコンソールで「ポリシー」→ポリシーを作成
```json
{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Effect": "Allow",
            "Action": "s3:PutObject",
            "Resource": "arn:aws:s3:::[PRIVATE_BUCKET_NAME]/*"
        }
    ]
}
```
`Lambda-to-S3-Minatomachi1-photos`などの名前でポリシーを保存



IAMコンソールで「ロール」→「ロールを作成」

信頼されたエンティティタイプ：**AWSのサービス**

ユースケース：**Lambda**

許可ポリシー
- `AWSLambdaBasicExecutionRole`を検索してチェック
- `Lambda-to-S3-Minatomachi1-photos`を検索してチェック
- 
  
`LambdaUploaderRole`などと名前をつけてロールを作成します。

- CatalogGenerator用のロールを作成
次のJSONでポリシーを作成する。
```json
{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Effect": "Allow",
            "Action": [
                "s3:ListBucket",
                "s3:GetObject"
            ],
            "Resource": [
                "arn:aws:s3:::[PRIVATE_BUCKET_NAME]",
                "arn:aws:s3:::[PRIVATE_BUCKET_NAME]/*"
            ]
        },
        {
            "Effect": "Allow",
            "Action": "s3:PutObject",
            "Resource": "arn:aws:s3:::[CATALOG_BUCKET_NAME]/*"
        }
    ]
}
```

ロールを作成から以下のロールを追加して`LambdaCatalogGeneratorRole`の名前で保存
- `AWSLambdaBasicExecutionRole`
- 先ほどJSONで作成したポリシー

## Lambda関数の作成
### Uploader関数の作成
「Lambda」コンソールで「関数を作成」をクリック

|名称|設定|
|----------|---------------|
|関数名|Uploader|
|ランタイム|Node.js 22.x|
|アーキテクチャ|x86_64|
「デフォルトの実行ロールの変更」から「既存のロールを使用する」を選択し、先ほど作成した`LambdaUploaderRole`を選択します。

### CatalogGenartor関数の作成
ローカル環境に`catalog-generator`などの適当なフォルダを作成します。

このフォルダ内で`CatalogGenerator`のコードを`index.mjs`として保存します。

このフォルダで新規ターミナルを開き`npm install qrcode`を実行します。

フォルダ内の全てのファイルを選択しZIPファイルに圧縮します。

**Lambdaコンソールでの作成**

Lambdaコンソールで`Uploader`と同じように関数を作成し、「コード」タブの「アップロード元」→「zipファイル」を選択します

先ほど作成したZIPファイルをアップロードします。

最後に処理がタイムアウトしないように「タイムアウト」を`3秒`から`10秒`に延長します。

## 写真自動削除ロジックの実装
### IAMロールの作成
IAMコンソールに移動し、「ポリシー」を作成。以下のJSONを貼り付ける。
`S3PhotoCleanerPolicy`などの名前をつけて保存。
```json
{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Effect": "Allow",
            "Action": [
                "s3:ListBucket",
                "s3:DeleteObject"
            ],
            "Resource": [
                "arn:aws:s3:::minatomachi1-photos",
                "arn:aws:s3:::minatomachi1-photos/*"
            ]
        }
    ]
}
```
IAMロールに移動し、「ロール」を作成、以下のポリシーを選択して作成
- `S3PhotoCleanerPolicy`
- `AWSLambdaBasicExecutionRole`

### Lambda関数の作成
先ほどと同じようにして関数を作成し、`index.mjs`にコードを貼り付け。

削除する写真が多い場合に備えて、タイムアウトをデフォルトの3秒から`1分`に延長しておく。
### Amazon EventBridgeコンソールでの設定
左側メニューの「スケジュール」から「スケジュールを作成」
