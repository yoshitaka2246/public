## s3をトリガーにしたLambda起動
渡されるevent object
```json
{
  "Records": [
    {
      "eventVersion": "2.1",
      "eventSource": "aws:s3",
      "awsRegion": "ap-northeast-3",
      "eventTime": "2025-10-13T05:30:00.000Z",
      "eventName": "ObjectCreated:Put", // ファイルが作成されたことを示す
      "userIdentity": {
        "principalId": "AWS:..."
      },
      "s3": {
        "s3SchemaVersion": "1.0",
        "configurationId": "...",
        "bucket": {
          "name": "indycruise-photos", // 🚨 必要な情報 (バケット名)
          "ownerIdentity": {
            "principalId": "..."
          },
          "arn": "arn:aws:s3:::indycruise-photos"
        },
        "object": {
          "key": "2025-10-07/CRUISE-001/photo1.jpg", // 🚨 必要な情報 (ファイルキー/パス)
          "size": 123456,
          "eTag": "...",
          "sequencer": "..."
        }
      }
    }
    // S3は基本的に一つのLambda起動で一つのレコード（イベント）を送るが、
    // 稀に複数のレコードを含むことがあるため、コードでは Records[0] を参照するのが一般的です。
  ]
}
```
