# ELB
ELB(Elastic Load Balancer)とは、複数のサーバー（EC2など）に対してアクセスを自動的に分散するサービスです。
ユーザーからのリクエストを1台のサーバーに集中させるのではなく、複数のサーバーに振り分けることで、負荷分散・可用性向上・スケーラビリティ確保を実現します。

一言で言うと、「アクセスをさばく入口」です。

ELBには、ALB、NLB、CLB（旧世代）の３種類あります。

### ALB
ALB(Application Load Balancer)とは、HTTP/HTTPS（Webアプリ）向けのロードバランサーで、アプリケーション層（L7）で動作し、リクエストの内容を見て振り分けることができるのが最大の特徴です。



### NLB
NLB(Network Load Balancer)とは、TCP/UDPレベルで動く超高速ロードバランサーです。ネットワークそう（L4）で動作し、リクエストの中身を見ずにそのまま転送します。


### CLB
CLB(Classic Load Balancer)は、旧世代のロードバランサーで、L4とL7の両方に対応していますが、機能が少なく新規で使われることはありません。
