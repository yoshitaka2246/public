# EC2インスタンスを活用した海外からの検索結果調査
　今回は、AWSのEC2を活用して、海外でインスタンスを起動し、海外からの検索結果を調査する方法をまとめます。
## EC2とは
EC2とは、一言で言えば「AWS上に作る、あなた専用の仮想サーバー」です。主な特徴は以下の通りです。
1. 自由自在なスペック変更
   - 小さなサーバーから、スーパーコンピュータ並みの高性能サーバーまで、数クリックで生成・削除が可能です。
   - 「調査が終わったから削除」「アクセスが増えたから台数を増やす」ということが柔軟にできます
2. OSやソフトの完全な制御権
   - Windows, Linux, macOSなど多様なOSを選べます。
   - 管理者権限を持てるため、好きなソフトウェアを自由にインストールできます。
3. 従量課金
   - 使った時間だけ料金が発生します。秒単位で計算されます。
   - 初期費用は不要で、使わなければ料金はかかりません。

Webサイトの公開や、業務システムの運用、海外からのアクセス調査やデータ解析を行うために主に使われます。

## 具体的な手順
今回は、GUIでブラウザを使って調査したいため、Windows Serverのインスタンスを立ち上げる方法で調査します。
### 1. リージョンの切り替え
AWSのリージョンを調査したい国に設定します。今回は、アメリカの検索結果を見たいため、バージニア北部(`us-east-1`)を選択します。

イギリスの場合はロンドン(`eu-west-2`)、オーストラリアの場合はシドニー(`ap-southeast-2`)を選択します。
### 2. Windowsインスタンスを起動する
次に現地のWindowsPCを一台借りる作業に入ります。
1. AWSコンソールから**EC2**を検索し、開きます。
2. 「インスタンスを起動」というオレンジのボタンをクリックします。
3. 以下の設定を行います。
   1. 名前：`US-reserch-PC`など。
   2. アプリケーションおよびOSイメージ：Windowsを選択肢、マシンイメージに`Microsoft Windows Server 2025 base`などが選択されていることを確認します。（デフォルトで大丈夫です）
   3. インスタンスタイプ：今回はブラウザを快適に操作したいため、`m7i-flex.large`を選択します。
   4. キーペア
      - **「新しいキーペアの作成」**をクリックします。
      - `us-key`などのように名前をつけます。
      - `RSA`, `.pem`を選択して作成します。
      - `xxx.pem`というファイルがダウンロードされます。
      - 残りはデフォルト値にしてインスタンスを起動します。
4. パスワードを取得して接続する。
   1. EC2のメニューから「インスタンス」をクリックし、作成したインスタンスを選択します。
   2. ステータスが「実行中」になり、システムステータスのチェックが「2/2」になるまで待ちます。
   3. 画面右上の「接続」をクリックします。
   4. 「RDPクライアント」タブを選択します。
   5. 「パスワードを取得」→「プライベートキーファイルのアップロード」をクリックし、先ほどダウンロードした`.pem`ファイルをアップロードします。
   6. 「パスワードを復号化」をクリックすると、パスワードが表示されるのでコピーしておきます。
5. 「リモートデスクトップファイルのダウンロード」ボタンをクリックします
  
### 3. 調査を行う
1. ダウンロードしたRDPファイル(`.rdp`)を実行します。
2. パスワードを求められるので、先ほど復号化したパスワードを入力します。
3. Windowsのデスクトップ画面が表示されます。
4. セキュリティを緩めます（これをしないとまともにブラウジングできません）
   1. スタートメニューから「サーバーマネージャー」を開きます
   2. ローカルサーバーを選択します
   3. 「IE Enhanced Security Configuration」を探します。
   4. 設定をオフにします。（Administratorsの方をオフにします）
5. コマンドでChromeをインストールします。
   1. 以下のコマンドをPowe shellで実行します

```PowerShell
$Path = $env:TEMP; $Installer = "chrome_installer.exe"; Invoke-WebRequest "http://dl.google.com/chrome/install/375.126/chrome_installer.exe" -OutFile $Path\$Installer; Start-Process -FilePath $Path\$Installer -Args "/silent /install" -Verb RunAs -Wait; Remove-Item $Path\$Installer
```

### インスタンスを削除
調査が終わったら、課金が継続されないようにインスタンスを終了（削除）します。

EC2のコンソールから起動中のインスタンスを選択します。「インスタンスの状態」から「インスタンスを終了（削除）」をクリックします。このとき、インスタンスを停止だと課金が継続されてしまいます。
